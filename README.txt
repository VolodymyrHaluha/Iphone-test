NEON SPIN — виправлення створення чатів

1. Замініть app.js у корені репозиторію Iphone-test на файл з цього архіву.
2. Зробіть Commit changes і дочекайтеся публікації GitHub Pages.
3. Очистіть кеш сайту/Service Worker і перезавантажте сторінку.
4. Спробуйте створити приватний чат.

Виправлено помилку: раніше getDoc() викликався для ще неіснуючого приватного чату, що викликало permission-denied через захисні Firestore rules. Тепер спершу виконується setDoc(), а якщо чат існує — перевіряється доступ і відкривається поточний чат.

Якщо навіть новий груповий чат дає permission-denied, перевірте опубліковані правила Firestore з оригінального проєкту. Не використовуйте allow read, write: if true.
